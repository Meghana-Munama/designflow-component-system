# DesignFlow Component System

DesignFlow Component System is a frontend-focused academic project created to explore scalable UI architecture, reusable component development, responsive design implementation, and accessibility-focused frontend engineering.

## Project Type
University / Academic Frontend Architecture Project

## Technologies
- React
- JavaScript
- Tailwind CSS
- Figma concepts
- Design Tokens

## Features
- Reusable button, card, navigation, and input components
- Responsive layouts for desktop, tablet, and mobile
- Accessibility-oriented UI patterns
- Modular frontend folder structure
- Tailwind-based styling system
- Design-token-inspired visual consistency

## Project Goals
The goal of this project was to improve frontend maintainability and scalability by building reusable component-driven UI structures similar to modern enterprise frontend workflows.

## Folder Structure
```bash
src/
 ┣ components/
 ┃ ┣ Button.jsx
 ┃ ┣ Card.jsx
 ┃ ┣ Navbar.jsx
 ┃ ┗ InputField.jsx
 ┣ styles/
 ┃ ┗ index.css
 ┣ App.jsx
 ┗ main.jsx
```

## How to Run
```bash
npm install
npm run dev
```

## Interview Talking Points
- Built reusable React components to reduce duplicate UI implementation.
- Used Tailwind CSS for consistent and scalable styling.
- Applied responsive design principles across layout sections.
- Used semantic HTML and visible focus states for accessibility.
- Structured the project to resemble a small frontend design system.
